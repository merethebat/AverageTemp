# Average Temperature

This is a simple Java program that calculates the average temperature from the values entered by the user.

## How It Works

* The user enters the number of temperatures.
* The program asks for each temperature.
* It calculates the average.
* It counts how many temperatures are above the average.

## How to Run

Compile and run the program using:

```bash
javac AverageTemperature.java
java AverageTemperature
```
